My Contributions

Weapon & Targeting System

Architectural Focus: Categorized Weapon Classes & Automated Targeting Logic

  • Archetype-Based Arsenal: Designed 3 distinct cannon categories (Controllable, Close-Range, Long-Range) totaling 9 unique weapons, each balance-tuned via Data Table parameters.
  • Automated Target Prioritization:
    • Close-Range: Scans for and prioritizes nearby low-health threats.
    • Long-Range: Filters for stronger targets farther away, balancing heavy damage output with lower rate-of-fire cooldowns.
  • Custom Aiming & Tracking: Built dynamic tracking math driven by exposed attributes (Turn Speed, Range, Cooldown, Damage) for crisp visual feedback and accurate lead-firing.

Dynamic Upgrade System

Architectural Focus: C++ & Gameplay Ability System (GAS) Integration

  • GAS-Backed Modifications: Integrated Unreal Engine’s Gameplay Ability System (GAS) to drive ship and cannon upgrades via dynamic GameplayEffects.
  • C++ Stat Binding: Extended base GAS attributes in C++ to expose boat and weapon stats (damage, fire rates, ranges), enabling clean additive, multiplicative, or balanced upgrade logic.
  • Data Asset Visual Mapping: Paired gameplay modifier logic with Data Assets to bundle runtime attributes alongside UI metadata (icons, display names, descriptions) for easy asset management.

Data Architecture & Balancing Tools

Architectural Focus: Centralized Data Tables & Composite Data Tables

  • Composite Stat Management: Structured multi-tier enemy stats using Composite Data Tables, consolidating individual enemy scaling tiers into a single unified matrix for fast cross-comparison.
  • Rapid Prototyping Workflow: Externalized all critical gameplay variables—including cannon attributes, level segments, and upgrade paths—into Data Tables to eliminate hardcoded Blueprint values.
  • Designer Velocity: Enabled zero-recompile balance adjustments, allowing designers to tweak weapon feel and enemy difficulty curves directly inside table editors.

Procedural Level Generation

Architectural Focus: Data-Driven Modular Generation

  • Weighted Segment Selection: Built a procedural level layout system using pre-constructed level segments mapped to difficulty thresholds in Data Tables.
  • Smart Flow & Anti-Repetition: Implemented logic to track recent segment selection, ensuring no back-to-back duplicate segments appear while dynamically scaling difficulty based on player progression.
  • Designer-Friendly Iteration: Separated level data into modular Data Tables, allowing designers to add, remove, or reorder level segments instantly without touching code or core level Blueprints.
