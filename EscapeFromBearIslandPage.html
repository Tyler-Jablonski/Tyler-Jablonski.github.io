Escape From Bear Island

Vancouver Film School • Gameplay Engineering

Overview

Escape from Bear Island is a 3D 3rd person Chibi style action-adventure game with a grumpy middle-aged lumberjack in the woods who is trying to escape from the island and return home to his wife, but finds his path blocked by sloths of bears. So in order to return safely to his house, he has to kill all the bears using his reliable axe.

My Contributions

Finite State Machine Enemy AI

  • State-Driven Behavior: Engineered enemy AI systems using Finite State Machines (FSM) to handle dynamic behavioral transitions (Patrol, Chase, Attack).
  • Perception & Combat: Scripted perception logic to switch enemies from environmental roaming to aggressive pursuit and melee attacks based on proximity and line-of-sight checks.

Pickups & Inventory Mechanics

  • Core Pickup Architecture: Designed and implemented three gameplay pickups (Honey Drops, Healing Flowers, Bear Traps) to enrich the core loop.
    • Honey Drops: Drops from defeated enemies to restore player stamina.
    • Healing Flowers: Provides instant health restoration.
    • Bear Traps: Integrates with an inventory system allowing secondary action placement (Right Click) to deal massive damage and apply a 3-second stun to incoming enemies.

In-Engine Debug & Tooling

  • Developer Suite: Built custom in-game debug tools—including checkpoint teleportation, toggleable god mode, infinite stamina, and live stat modifiers—to accelerate playtesting and balance iteration.
  • Workflow Optimization: Streamlined QA and feature testing across late-game scenarios, eliminating test friction and reducing iteration cycles for the team.

Local Saving & Checkpoint System

  • Persistent Progression: Built a local save/load system using Unity PlayerPrefs to retain player progress across game sessions.
  • Visual Checkpoints: Implemented interactive bonfire checkpoints that trigger flame visual effects upon activation, offering clear player feedback and serving as dynamic respawn anchors upon player death.
